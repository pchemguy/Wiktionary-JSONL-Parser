# Wiktionary JSONL Parser

Wiktionary JSONL Parser is a toolkit in development for working with Wiktionary extracts published by Kaikki.org. The initial converter will read an extracted Russian Wiktionary JSONL file and create a relational SQLite database for querying and postprocessing.

See the [project brief](docs/dev/PROJECT.md) for the proposed input, output, and import behavior.
