# Milestone 1.1 — Entry import

Integrated tasks T-001 through T-003. The CLI initializes the canonical 21-table schema and writes entry rows and batch log rows in one transaction per source batch.

Reviewed the CLI, UTF-8 and JSON decoding, mapper, and the destination and transaction lifecycles. The destination is created exclusively after the input open and SQLiteICUex checks. Duplicate keys use the decoded last value, while duplicate records retain separate IDs. A prior commit survives failure during decode or a later SQLite write.

On Debian 13 with CPython 3.12.14 and SQLite 3.54.1 with SQLiteICUex, pytest passed 31 tests with two missing-collation checks skipped. Standard SQLite separately exercised the missing-collation CLI and verified the destination stayed absent. Ruff and mypy passed.

The initial T-001 commit included generated bytecode and preceded a passing negative-runtime test. Its forward correction removed the bytecode, added ignore rules, and verified both runtime cases before closing issue #10.
