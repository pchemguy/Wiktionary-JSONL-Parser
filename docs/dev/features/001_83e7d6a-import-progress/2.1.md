# Milestone 2.1 — Progress logging

The importer counts the original binary line lengths and calls the optional observer after the completed SQLite write. The observer test independently queried `batch_log` using another connection at each notification. The CLI prints a flushed line to stderr by default, and `--no-progress` preserves diagnostics alone. Progress tests cover BOM, CRLF, UTF-8, an unterminated final record, empty input, and failed decode, mapping, and write batches.

Ruff and strict mypy passed. The SQLiteICUex pytest run passed 62 tests with two standard-SQLite checks skipped. Those two checks passed on the standard runtime.
